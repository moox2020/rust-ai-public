开发环境搭建 —— 跟我做，跑通第一个项目

上一节讲完了为什么，这一节开始真正动手：装好 Rust toolchain，配好 VSCode + rust-analyzer，用 cargo new 建出第一个项目，然后跑通 Hello World。

时长约 15 分钟
形式安装 → 配置 → 建项目 → 跑起来
适合刚看完第1节、准备动手的你
第一步 · 安装 toolchain

用 rustup 一条命令装好 Rust

第二步 · 配置 IDE

VSCode 装上 rust-analyzer 就够用了

💡
小提示：打开 VSCode 扩展面板，搜索并安装 rust-analyzer（官方扩展，发布者 rust-lang）。装好后打开任意 .rs 文件，代码补全、类型提示、跳转定义会自动生效，不需要额外配置。
✅
顺手装：CodeLLDB（断点调试）和 Even Better TOML（Cargo.toml 高亮），后面几节会用到。
第三步 · 创建项目

cargo new 一次性生成完整骨架

跑起来

cargo run 跑通 Hello World

常见踩坑

国内网络下最容易卡的一步

⚠️
注意：首次 cargo run / cargo build 会去 crates.io 下载依赖索引，国内网络经常卡在这一步半天没反应，看起来像"卡死"，其实是在等超时。

配置一次，全局生效——cargo build / cargo run 的下载速度明显提升。

环境搭好了，下一节学异步基础
💡
小提示：第3节是异步编程速成——调用大模型API本质上都是异步网络请求，这是后面所有系列的地基。
